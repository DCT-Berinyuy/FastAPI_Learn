# FastAPI_Learn
This comprehensive 19-hour course, taught by Sanjeev Thiyagarajan, is designed to guide beginners through building a full-featured API using FastAPI in Python (0:00 - 0:35). The course covers the entire development lifecycle, from basic API design to deployment and testing.

## Key Learning Pillars:
API Fundamentals: You will learn how to handle HTTP requests, route management, schema validation with Pydantic, and how to implement authentication using JWT tokens (0:39 - 1:07, 6:32 - 7:38).
Database Management: A significant portion of the course is dedicated to SQL and PostgreSQL, teaching everything from basic queries to advanced database interactions using SQLAlchemy (ORM) and Alembic for migrations (2:24 - 4:08, 10:30 - 11:13).
Project Development: The course builds a social media-style application where users can create posts, manage CRUD operations, vote on content, and secure routes (6:34 - 10:28).
DevOps & Deployment: You will learn to containerize applications using Docker and Docker Compose, as well as how to deploy to production environments like Heroku or an Ubuntu VM with NGINX and SSL (12:05 - 13:20, 13:26 - 14:08).
Testing & CI/CD: The course concludes with extensive testing practices using pytest and building automated pipelines via GitHub Actions (14:14 - 15:06, 17:34 - 18:23).
